# mohamad-liyaghi.ir

Source for my personal site — a bilingual (English / فارسی), terminal-themed portfolio.

- **Stack:** Vite · React · TypeScript · Tailwind CSS · Framer Motion · i18next
- **Live:** https://mohamad-liyaghi.ir
- **Languages:** English (LTR) and Persian (RTL) with a one-tap switch
- **Deploy:** GitHub Actions → GitHub Pages

```bash
npm install
npm run dev      # local dev
npm run build    # production build → dist/
```
