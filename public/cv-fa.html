خلاصه

مهندس نرم‌افزارم؛ پنج سال کار با Python و تمام‌پشته با گرایش بک‌اند. در Zebracat سامانه‌های پشت ویدیوی مبتنی بر هوش مصنوعی را می‌سازم: خط‌لوله‌هایی که یک رندر را به کارهایی می‌شکنند که مستقل از هم شکست می‌خورند و دوباره تلاش می‌کنند، گام‌های مدل که متن و صحنه تولید می‌کنند، ویدیوی برنامه‌پذیر با Remotion، و رابط‌های React روی همهٔ این‌ها. دربارهٔ رفتار واقعی مدل‌های زبانی زیر بار کاربر می‌نویسم.

شهریور ۱۴۰۳ — اکنون · دورکاری (برلین)

Zebracat · پلتفرم ساخت ویدیو از متن

  • ساخت خط‌لولهٔ تولید: هر رندر به کارهایی شکسته می‌شود که مستقل از هم روی کارگرهای RabbitMQ دوباره تلاش می‌کنند و وضعیت هر کار جداگانه نگه داشته می‌شود، تا شکست یک مرحله به قیمت کل ویدیو تمام نشود.
  • کار روی بخش مدلِ محصول — ساخت متن و صحنه، اعتبارسنجی خروجی با شِما پیش از رسیدن به خط‌لوله، و تلاش مجددی که نمی‌گذارد یک پاسخ نامعتبر کل رندر را خراب کند.
  • ساخت ویدیوی برنامه‌پذیر با Remotion: کامپوننت‌های React که بدون مرورگر به فریم تبدیل می‌شوند، تا تغییر یک قالب مثل هر تغییر کد دیگری منتشر شود.
  • کار در همهٔ لایه‌ها — سرویس‌های Django و FastAPI پشت رابط‌های React و TypeScript.

Python · FastAPI · Django · RabbitMQ · Redis · React · TypeScript · Remotion · Docker · AWS

پروژه‌های متن‌باز منتخب

۲۲۹ ستاره در ۲۳ مخزن عمومی · github.com/mohamad-liyaghi

  • FoodAnywhere ۴۰ ستاره — بک‌اند سفارش غذا. PostGIS برای جست‌وجوی مکانی، Celery برای کارهای سنگین، و ردیابی‌ای که سفارش را از درخواست تا کارگر دنبال می‌کند.
  • fast-commerce ۲۲ ستاره — بک‌اند فروشگاهی ناهمگام با تمرکز بر توان عملیاتی — مرزهای تمیز API، پردازش پس‌زمینه، و آزمون‌هایی که جلوی انتشار خراب را می‌گیرند.
  • AcademyMaster ۲۱ ستاره — API مدیریت آموزشگاه با دسترسی‌های لایه‌ای و کارهای زمان‌بندی‌شدهٔ پس‌زمینه.
  • Tsuna-Streaming ۱۶ ستاره — بک‌اند پخش ویدیو و موسیقی، با انتقال پردازش‌های سنگین به کارگرهای پس‌زمینه.
  • telegram-to-rubika-uploader ۱۴ ستاره — ابزار Go برای انتقال فایل تا ۲ گیگابایت میان دو پلتفرم، تا کاربران ایرانی پهنای باند محدود VPN را صرف آپلود دوباره نکنند.
  • FastQuora ۱۱ ستاره — سامانهٔ پرسش و پاسخ روی FastAPI — جست‌وجو با Elasticsearch، کش با Redis، و ردیابی توزیع‌شده در هر دو.
