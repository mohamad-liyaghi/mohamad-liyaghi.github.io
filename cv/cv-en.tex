\cvsection{Summary}

Software engineer, five years of Python, mostly backend. At Zebracat I work on the path from a prompt
to a rendered video: jobs that retry on their own, model output that has to pass a schema, and Remotion
templates that ship like code. I write about language-model systems once they have real users.

\cvsection{Experience}

\role{Software Engineer \textperiodcentered\ AI}{Zebracat}{Generative text-to-video platform}{Sep 2024 \textendash\ Present \textperiodcentered\ Remote (Berlin)}
\begin{cvbullets}
  \item A failed scene no longer kills the render. Each step is a job on RabbitMQ, with its own
        state and its own retry.
  \item Scripts and scenes are generated, then checked against a schema. A bad response retries;
        it does not take the video down.
  \item Templates are Remotion \textemdash\ React rendered headlessly into frames. Changing one
        is a code change.
  \item Django and FastAPI services behind React and TypeScript.
\end{cvbullets}
\tech{Python \textperiodcentered\ FastAPI \textperiodcentered\ Django \textperiodcentered\ RabbitMQ \textperiodcentered\ Redis \textperiodcentered\ React \textperiodcentered\ TypeScript \textperiodcentered\ Remotion \textperiodcentered\ Docker \textperiodcentered\ AWS}
