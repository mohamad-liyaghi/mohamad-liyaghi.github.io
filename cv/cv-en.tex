\cvsection{Summary}

Software engineer, five years in Python and backend-leaning full-stack. I build the systems behind
AI video at Zebracat: job pipelines that split a render into work which can fail and retry on its own,
the model steps that generate scripts and scenes, programmatic video with Remotion, and the React
interfaces on top. I write publicly about how language-model systems behave under real traffic.

\cvsection{Experience}

\role{Software Engineer \textperiodcentered\ AI}{Zebracat}{Generative text-to-video platform}{Sep 2024 \textendash\ Present \textperiodcentered\ Remote (Berlin)}
\begin{cvbullets}
  \item Build the generation pipeline: a render is split into jobs that retry independently
        across RabbitMQ workers, with state held per job so one failed step doesn't cost the
        whole video.
  \item Work on the model side of the product \textemdash\ script and scene generation, output
        validated against a schema before it reaches the pipeline, and retries that keep one bad
        response from failing a render.
  \item Build programmatic video with Remotion: React components rendered headlessly into
        frames, so changing a template ships like any other code change.
  \item Work across the stack \textemdash\ Django and FastAPI services behind React and
        TypeScript surfaces.
\end{cvbullets}
\tech{Python \textperiodcentered\ FastAPI \textperiodcentered\ Django \textperiodcentered\ RabbitMQ \textperiodcentered\ Redis \textperiodcentered\ React \textperiodcentered\ TypeScript \textperiodcentered\ Remotion \textperiodcentered\ Docker \textperiodcentered\ AWS}
